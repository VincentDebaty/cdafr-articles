# CDAFR — Articles traduits par Daniel Kmiecik

Ce dépôt héberge les fichiers PDF des articles traduits en français par
Daniel Kmiecik, référencés dans le catalogue du **Centre de documentation
anthroposophique francophone regroupé (CDAFR)**.

Il remplace l'ancien hébergement `www.idcch.be/wp-content/uploads/`, devenu
inaccessible depuis que le domaine `idcch.be` redirige vers le site Notion
du centre.

Les fichiers sont servis via GitHub Pages :
`https://vincentdebaty.github.io/cdafr-articles/<nom-du-fichier>.pdf`

Publication faite avec l'accord de Daniel Kmiecik.
